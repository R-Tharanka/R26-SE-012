# Current Repository Guides

These documents describe how to build, run, inspect, and validate the current
repository and its research/application workflow. They are operational guides
and indexes, not frozen result records.

| Guide | Purpose |
|---|---|
| `build_guide.md` | Primary build, backend, Flutter, and hosted-service usage guide |
| `repository_inventory.md` | Repository-wide ownership, authority, history, and cleanup map |
| `PHASE7_APPLICATION_RUN_GUIDE.md` | Run the Phase 7 backend/mobile workflow and perform focused application checks |
| `project_commands_guide.md` | Command reference for backend and research workflows, including historical reproduction commands |

For research conclusions and frozen evidence, use the V3 and Phase 4-7 result
documents under `../research/`.
